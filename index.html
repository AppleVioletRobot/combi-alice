    About Combinatorial Alice

    Combinatorial Alice is an exploratory identity artefact. Turn the four sections to assemble a temporary Alice.

    Each component remains available even when it is not selected. No combination is definitive.

    Use the arrow buttons or drag a row. Lock any component you want to preserve before choosing Random Alice.
