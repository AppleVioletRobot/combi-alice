# Combinatorial Alice

An exploratory identity artefact. Drag or turn the four carousels to assemble a temporary Alice.

## Adding a component

1. Put the 800 × 800 PNG in the matching folder under `alice/`: `heads`, `torsos`, `legs`, or `feet`.
2. Add its stable ID, filename, display name and alt text to the matching array in `components.json`.

The four categories do not need to contain the same number of parts. The application calculates the number of possible Alices automatically.
